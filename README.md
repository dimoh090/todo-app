# To-Do-менеджер на Go

Консольное приложение для управления задачами по изучению Go.

Возможности:
- добавление задач;
- просмотр всех, выполненных и невыполненных задач;
- отметка задачи выполненной;
- удаление задачи;
- экспорт и импорт в форматах JSON и CSV.

## Структура проекта

- `cmd/todo/main.go` — обработка команд и флагов.
- `internal/todo/task.go` — структура Task.
- `internal/todo/manager.go` — добавление, фильтрация, выполнение и удаление задач.
- `internal/storage/json_storage.go` — чтение и запись JSON.
- `internal/storage/csv_storage.go` — чтение и запись CSV.
- `go.mod` — описание модуля Go.
- `tasks.json` — основное хранилище задач.

## Сборка и запуск

Требуется установленный Go. Версия, указанная в go.mod,
должна поддерживаться установленным Go.

Откройте терминал в корневой папке проекта — там, где лежит go.mod.

Сборка для Windows:

```powershell
go build -o todo.exe ./cmd/todo
```

Просмотр справки:

```powershell
.\todo.exe help
```

Также приложение можно запускать без отдельной сборки:

```powershell
go run ./cmd/todo help
```

## Примеры команд

Добавить задачу:

```powershell
.\todo.exe add --desc="Изучить срезы Go"
```

Посмотреть задачи:

```powershell
.\todo.exe list --filter=all
.\todo.exe list --filter=done
.\todo.exe list --filter=pending
```

Если фильтр не указан, показываются все задачи.

Отметить задачу выполненной:

```powershell
.\todo.exe complete --id=1
```

Удалить задачу:

```powershell
.\todo.exe delete --id=1
```

Вместо 1 укажите ID нужной задачи из вывода команды list.

Экспортировать задачи:

```powershell
.\todo.exe export --format=csv --out=export.csv
.\todo.exe export --format=json --out=export.json
```

Импортировать задачи:

```powershell
.\todo.exe load --file=export.csv
.\todo.exe load --file=export.json
```

Важно: импорт заменяет текущий список задач.
Экспорт перезаписывает указанный выходной файл, если он существует.

## Хранение данных

Задачи хранятся в tasks.json в текущей папке терминала.
Если файл отсутствует, при загрузке основного хранилища
приложение создаёт JSON-файл с пустым списком.

Каждая задача содержит:
- ID — целочисленный идентификатор;
- Description — описание;
- Done — статус выполнения: true или false.

CSV использует заголовок ID,Description,Done.

## Обработка ошибок

Приложение проверяет пустое описание, неправильные фильтры,
некорректные ID, неизвестные команды и неподдерживаемые форматы.

Ошибки чтения, записи и разбора файлов передаются пользователю.
При ошибке команда завершается с кодом 1.

## Ручная проверка

Проверены:
- добавление и просмотр задач;
- отметка выполненной и фильтрация;
- удаление;
- экспорт и импорт JSON и CSV;
- неправильный ввод и отсутствие файла импорта.
